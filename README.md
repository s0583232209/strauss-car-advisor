# יועץ הרכב שטראוס (Yoetz HaRechev)

מערכת חכמה ומדויקת להשוואת שכר נטו, כלי רכב חשמליים, מסלול ברוכת ילדים, ויתור על רכב וחישוב שווי שימוש לעובדי קבוצת שטראוס.

## תכונות עיקריות
- **מנוע חישוב שכר טהור ב-TypeScript (`/engine`):** חישוב מדרגות מס הכנסה חודשיות (2025), ביטוח לאומי ומס בריאות, זיכוי פנסיוני (סעיף 45א), נקודות זיכוי ודמי אחזקה. המודל הלשוני לעולם אינו מחשב או ממציא מספרים בעצמו.
- **סוכן חכם מבוסס Gemini (`@google/genai`):** ממשק שיחה בעברית עם Function Calling, חילוץ רב-מודאלי מתלושי שכר וחוזים, מנגנון Guardrails קפדני למניעת הזיות חישוביות.
- **הגנה על מכסות חינמיות (Free-Tier Safety):** מנגנון Exponential Backoff עם Jitter בעת שגיאות 429/503, הגבלה ל-6 קריאות לכל תור שיחה, זיכרון מטמון (In-memory cache) וספק גיבוי (Fallback).
- **שכבת אחסון כפולה (`StorageAdapter`):** מימוש ברירת מחדל ב-`LocalStorage` עם סנכרון חוצה-כרטיסיות באמצעות אירועי Storage ו-Polling, ומימוש `Supabase` לסנכרון זמן אמת חוצה מכשירים (`/supabase/schema.sql`).
- **מאגר שווי שימוש רשות המסים (IndexedDB):** פענוח קובץ CSV של כ-78,000 שורות בקידוד `windows-1255`, אחסון ושליפה לפי מפתח 4-Tuple רשמי `(שנת רישום, קוד סוג רכב 1, קוד תוצר, קוד דגם)`.
- **מסכי מערכת מלאים (Hash routes):**
  - `#/` - מסך עובד: צ'אט, פאנל פרופיל שנאסף הניתן לעריכה ישירה, כרטיס השוואה מלא, תרשים Waterfall מובנה SVG, העלאת תלוש שכר וכפתורי דמו.
  - `#/rep` - מסך נציג שכר: רשימת פניות, פירוט נתוני עובד ותמצית בוט, טופס מענה עם שדות מובנים (ערך השתתפות ותאריך תוקף) המעדכנים מיד את העובד.
  - `#/admin` - מסך ניהול ובדיקות: עריכת כללי JSON, קטלוג, עיסוקים, לוחות מס, טוען CSV רשות המסים, הנחות יסוד, ומערכת בדיקות כיול (Calibration Tests) ב-100% הצלחה (דיוק של ±1 ₪).
  - `#/guide` - מדריך הפעלה ונהלים רשמי המיוצר ישירות מתוך קונפיגורציית האפליקציה החיה.

## התקנה והרצה מקומית

```bash

npm run build
```

## משתני סביבה (`.env`)

ראו פירוט מלא בקובץ `.env.example`:
- `GEMINI_API_KEY`: מפתח ה-API של Gemini (מוזרק אוטומטית בסביבת AI Studio).
- `APP_URL`: כתובת ה-URL של האפליקציה.
- `PORT`: פורט ההאזנה (ברירת מחדל 3000).
- `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`: משתנים אופציונליים להפעלת Supabase Realtime.
- `VITE_FALLBACK_BASE_URL` / `VITE_FALLBACK_KEY` / `VITE_FALLBACK_MODEL`: ספק גיבוי אופציונלי תואם OpenAI בעת חריגת מכסות ממושכת.

3. רחל (ויתור 1,500 ← MG4): נטו היום 15,047 ₪, נטו חלופה 13,109 ₪, הפרש −1,938 ₪, גילום 473 ₪.
4. יוסי (TUCSON ← EV3): נטו היום 10,693 ₪, נטו חלופה 11,900 ₪, הפרש +1,207 ₪, גילום 440 ₪.
5. מיכל (MAZDA 3 ← ויתור 2,000): נטו היום 14,244 ₪, נטו חלופה 17,806 ₪, הפרש +3,562 ₪.

## החלפת נתונים עבור פיילוט
הפילוסופיה של המערכת היא שפיילוט מחליף נתונים ולא קוד:
- קובץ הכללים: `/data/strauss-rules.json` (תקציבים, מדרגות, כללים).
- קטלוג הרכבים: `/src/data/catalog.json`.
- טבלת העיסוקים: `/src/data/occupations.json`.
- מאגר רשות המסים: ניתן להעלות קובץ CSV עדכני דרך מסך הניהול.
