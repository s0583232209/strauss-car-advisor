# יועץ הרכב שטראוס (Yoetz HaRechev)

מערכת חכמה ומדויקת להשוואת שכר נטו, כלי רכב חשמליים, מסלול ברוכת ילדים, ויתור על רכב וחישוב שווי שימוש לעובדי קבוצת שטראוס.

## ארכיטקטורה (3 שכבות)
- **לקוח (`src/`):** React + Tailwind. מדבר רק עם ה-API דרך `src/api/client.ts`, בלי מפתחות, בלי מנוע ובלי גישה למסד הנתונים.
- **שכבת API (`server/api/`):** Express. בדיקות קלט, CORS, הגבלת קצב, קודי גישה לנציג ולמנהל, טיפול בשגיאות.
- **לוגיקה עסקית (`server/bl/`):** מנוע השכר, האיגנט והכלים, בדיקת המספרים, חיבור ל-Gemini.
- **גישה לנתונים (`server/dal/`):** Supabase עם מפתח שרת בלבד, או קבצי JSON מקומיים בפיתוח.
- טיפוסים משותפים: `shared/types.ts`. פריסה לענן: `docs/DEPLOY.md`.

## תכונות עיקריות
- **מנוע חישוב שכר טהור ב-TypeScript (`server/bl/engine`):** חישוב מדרגות מס הכנסה חודשיות (2025), ביטוח לאומי ומס בריאות, זיכוי פנסיוני (סעיף 45א), נקודות זיכוי ודמי אחזקה. המודל הלשוני לעולם אינו מחשב או ממציא מספרים בעצמו.
- **סוכן חכם מבוסס Gemini (`@google/genai`):** ממשק שיחה בעברית עם Function Calling, חילוץ רב-מודאלי מתלושי שכר וחוזים, מנגנון Guardrails קפדני למניעת הזיות חישוביות.
- **הגנה על מכסות חינמיות (Free-Tier Safety):** מנגנון Exponential Backoff עם Jitter בעת שגיאות 429/503, הגבלה ל-6 קריאות לכל תור שיחה, זיכרון מטמון (In-memory cache) וספק גיבוי (Fallback).
- **אחסון בשרת (`Repository`):** Supabase עם `SUPABASE_SERVICE_ROLE_KEY` ו-RLS נעול (`/supabase/schema.sql`), או קבצי JSON מקומיים כשאין Supabase. לכל דפדפן שיחה משלו.
- **מאגר שווי שימוש רשות המסים (בשרת):** פענוח קובץ CSV של כ-78,000 שורות בקידוד `windows-1255`, אחסון ושליפה לפי מפתח 4-Tuple רשמי `(שנת רישום, קוד סוג רכב 1, קוד תוצר, קוד דגם)`.
- **מסכי מערכת מלאים (נתיבי URL: `/:userId/pagename`):**
  - `/:userId/employee` - מסך עובד: צ'אט, פאנל פרופיל שנאסף הניתן לעריכה ישירה, כרטיס השוואה מלא, תרשים Waterfall מובנה SVG, העלאת תלוש שכר וכפתורי דמו.
  - `/:userId/rep` - מסך נציג שכר: רשימת פניות, פירוט נתוני עובד ותמצית בוט, טופס מענה עם שדות מובנים (ערך השתתפות ותאריך תוקף) המעדכנים מיד את העובד.
  - `/:userId/admin` - מסך ניהול ובדיקות: עריכת כללי JSON, קטלוג, עיסוקים, לוחות מס, טוען CSV רשות המסים, הנחות יסוד, ומערכת בדיקות כיול (Calibration Tests) ב-100% הצלחה (דיוק של ±1 ₪).
  - `/:userId/guide` - מדריך הפעלה ונהלים רשמי המיוצר ישירות מתוך קונפיגורציית האפליקציה החיה.

## התקנה והרצה מקומית

```bash
# התקנת תלויות

# הרצת שרת פיתוח מלא (Express + Vite) על פורט 3000
npm run dev

# בנייה לפרודקשן (dist/ + dist-server/) והרצה

# בדיקות טיפוסים ובדיקות
```

## משתני סביבה (`.env`)

כל המשתנים נקראים בשרת בלבד. פירוט מלא ב-`.env.example` וב-`docs/DEPLOY.md`:
- `GEMINI_API_KEY`, `GEMINI_MODEL`: המפתח ורשימת המודלים לפי סדר עדיפות.
- `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY`: אחסון וכניסת משתמשים (Supabase Auth). חובה בפרודקשן, שניהם או אף אחד. בלעדיהם אין כניסה וכל המסכים פתוחים (פיתוח בלבד).
- הרשאות: עובד רואה את מסך העובד, נציג רואה גם את מסך הנציג, ומנהל רואה הכול. התפקיד נשמר בטבלה `app_users`.
- `FALLBACK_BASE_URL` / `FALLBACK_API_KEY` / `FALLBACK_MODEL`: ספק גיבוי אופציונלי תואם OpenAI.
- `PORT`, `TRUST_PROXY`, `ALLOWED_ORIGINS`, `DATA_DIR`.

2. דוד (NIRO ← CARNIVAL): נטו היום 8,600 ₪, נטו חלופה 5,078 ₪, הפרש −3,522 ₪, חלק עובד בפער 1,150 ₪.
3. רחל (ויתור 1,500 ← MG4): נטו היום 15,047 ₪, נטו חלופה 13,109 ₪, הפרש −1,938 ₪, גילום 473 ₪.
4. יוסי (TUCSON ← EV3): נטו היום 10,693 ₪, נטו חלופה 11,900 ₪, הפרש +1,207 ₪, גילום 440 ₪.
5. מיכל (MAZDA 3 ← ויתור 2,000): נטו היום 14,244 ₪, נטו חלופה 17,806 ₪, הפרש +3,562 ₪.
6. אלי (OCTAVIA ← MODEL 3): נטו היום 17,073 ₪, נטו חלופה 17,794 ₪, הפרש +721 ₪, גילום 473 ₪.

## החלפת נתונים עבור פיילוט
הפילוסופיה של המערכת היא שפיילוט מחליף נתונים ולא קוד:
- קובץ הכללים: `/server/data/strauss-rules.json` (תקציבים, מדרגות, כללים).
- קטלוג הרכבים: `/server/data/catalog.json`.
- טבלת העיסוקים: `/server/data/occupations.json`.
- מאגר רשות המסים: ניתן להעלות קובץ CSV עדכני דרך מסך הניהול.
